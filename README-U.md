# NWT Linker

NWT Linker — это плагин сообщества для Obsidian, который превращает ссылки на библейские стихи в ссылки, открывающие «Перевод Нового мира» в JW Library или на сайте jw.org.

Введите в заметке название библейской книги и ссылку на главу/стих, и плагин преобразует её в ссылку, открывающую соответствующий отрывок в «Переводе Нового мира».

## Возможности

- Автоматически создаёт ссылки на библейские стихи по мере ввода
- Генерирует ссылки jw.org для «Перевода Нового мира»
- Открывает JW Library, если он доступен, иначе переходит на jw.org
- Поддерживает настраиваемые псевдонимы названий книг
- Загружает псевдонимы названий книг из предустановок WT Locale
- Добавляйте, редактируйте, удаляйте, импортируйте и экспортируйте псевдонимы в формате JSON
- Отслеживает, загружены ли псевдонимы из предустановки или отредактированы вручную
- Позволяет настроить локаль, издание и шаблон URL
- Использует короткую задержку после остановки ввода, чтобы не мешать редактированию

## Использование

Введите ссылку на библейский стих так:

```text
Тит1:14
```

Она будет преобразована в ссылку, например:

```md
[Тит 1:14](https://www.jw.org/finder?srcid=jwlshare&wtlocale=U&prefer=lang&bible=56001014&pub=nwtsty)
```

Это также работает, если между названием книги и главой есть пробел:

```text
Тит 1:14
```

## Псевдонимы названий книг

Вы можете задать псевдонимы для каждой библейской книги. Псевдонимы загружаются из предустановок в зависимости от вашей настройки **WT Locale**.

Например, предустановка для русского языка (`U`) включает такие псевдонимы:

- `Бытие`, `Быт` → Бытие
- `Псалмы`, `Пс` → Псалмы
- `Тит`, `Тит` → Тит
- `Иоанн`, `Ин` → Иоанн

Это позволяет преобразовывать ссылки, используя привычные сокращения.

В разделе **Book name aliases** в настройках вы можете:

- Добавлять псевдонимы
- Изменять номер книги для существующего псевдонима
- Удалять псевдонимы
- Импортировать или экспортировать псевдонимы в формате JSON
- **Load aliases for current WT Locale**: заменить текущие псевдонимы предустановкой, соответствующей вашей настройке WT Locale (например, `U — русский`).

### Пользовательские псевдонимы и перезагрузка предустановок

Когда вы добавляете, редактируете, удаляете или импортируете псевдонимы, список переходит в состояние **custom**. На экране настроек отображается, загружен ли текущий список из предустановки или отредактирован вручную.

Если вы находитесь в состоянии custom и выбираете **Load aliases for current WT Locale**, появится диалоговое окно подтверждения, чтобы вы случайно не перезаписали свои пользовательские псевдонимы. Если предустановка для текущей локали уже загружена, она будет немедленно перезагружена.

### Запрос новой языковой предустановки

Если вам нужна поддержка WT Locale, который ещё не включён, пожалуйста, создайте issue или pull request на [GitHub](https://github.com/jwnetdotwork/nwt-linker).

## Настройки

На экране настроек вы можете изменить следующие параметры:

- Включить или отключить преобразование
- Задержка перед преобразованием после остановки ввода
- Локаль открываемого издания
- Открываемое издание
- Шаблон URL

Если вы используете другой WT Locale, измените настройку локали в соответствии с вашим языком.

## Установка

### Ручная установка

1. Откройте страницу [Releases на GitHub](https://github.com/jwnetdotwork/nwt-linker/releases) и скачайте `main.js` и `manifest.json` из последнего релиза.
2. Поместите эти два файла в следующую папку вашего vault:

```text
<Vault>/.obsidian/plugins/obsidian-nwt-linker/
```

3. Перезагрузите Obsidian и включите NWT Linker в **Настройки → Сторонние плагины**.

## Примечания

- Поддерживаемые предустановки WT Locale:
  - Японский (`J`)
  - Английский (`E`)
  - Испанский (`S`)
  - Китайский мандарин традиционный (`CH`)
  - Китайский мандарин упрощённый (`CHS`)
  - Португальский бразильский (`T`)
  - Французский (`F`)
  - Немецкий (`X`)
  - Корейский (`KO`)
  - Итальянский (`I`)
  - Русский (`U`)
- Если для настроенного WT Locale нет предустановки, плагин при первой настройке использует японскую предустановку (`J`).
- Это плагин сообщества для Obsidian.
- По умолчанию работает в автономном режиме.
- Соблюдает правила использования jw.org и не выполняет скрейпинг контента.
- Преобразование ссылок на стихи происходит полностью внутри ваших заметок.
- Как узнать свой WT Locale
  - Создайте ссылку для совместного использования на вашем языке и найдите параметр `wtlocale=`. Заглавные буквы после него — ваш WT Locale.
  - Пример: В ссылке `https://www.jw.org/finder?srcid=jwlshare&wtlocale=U&prefer=lang&bible=40024045&pub=nwtsty` WT Locale равен `U`.

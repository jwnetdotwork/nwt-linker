# NWT Linker

NWT Linker は、入力された聖句を新世界訳として JW Library / jw.org で開けるリンクに変換する Obsidian プラグインです。

ノート内で聖書の書名と章節表現を入力すると、その参照を新世界訳の聖句リンクに変換します。生成されるリンクは JW Library / jw.org で開ける形式です。

## 主な機能

- 聖句参照を自動でリンク化
- 書名・章・節を入力すると、対応する jw.org の新世界訳リンクを作成。JW Library が入っていれば JW Library で、入っていなければ jw.org が開きます
- 書名のエイリアスを設定可能
- WT Locale（言語ロケール）のプリセットから書名エイリアスを読み込み
- エイリアスの追加、編集、削除、JSON のインポート・エクスポートに対応
- エイリアスがプリセット由来かカスタム編集かを追跡
- 言語、訳、URL テンプレートを設定可能
- 入力が止まってから一定時間後に変換するので、編集中の文字を邪魔しにくい

## 使い方

次のように聖句を入力します。

```text
テトス1:14
```

変換後は、たとえば次のようなリンクになります。

```md
[テトス1:14](https://www.jw.org/finder?srcid=jwlshare&wtlocale=J&prefer=lang&bible=56001014&pub=nwtsty)
```

書名のあいだに半角または全角スペースを入れても動作します。

```text
テトス 1:14
テトス　1:14
```

## 書名エイリアス

このプラグインでは、書名ごとにエイリアスを設定できます。エイリアスは **WT Locale** の設定に応じたプリセットから読み込まれます。

たとえば、日本語 (`J`) プリセットには次のようなエイリアスが含まれています。

- `創世記`, `創` → 創世記
- `詩編`, `詩` → 詩編
- `テトス`, `テト` → テトス
- `ヨハネ`, `ヨハ` → ヨハネ

これにより、普段使っている略称でもそのまま聖句リンクに変換できます。

設定画面の **Book name aliases** から、次の操作ができます。

- エイリアスの追加
- 既存エイリアスの書名番号変更
- エイリアスの削除
- JSON での一括インポート / エクスポート
- **Load aliases for current WT Locale**: 現在の WT Locale に対応するプリセットでエイリアスを置き換えます（例: `J — 日本語`）。

### カスタムエイリアスとプリセットの再読み込み

エイリアスを追加・編集・削除・インポートすると、エイリアス一覧は **custom（カスタム）** 状態になります。設定画面では、現在の一覧がプリセットから読み込まれたものか、カスタム編集されたものかが表示されます。

custom 状態で **Load aliases for current WT Locale** を選択すると、カスタムエイリアスを誤って上書きしないよう確認ダイアログが表示されます。現在のロケールのプリセットがすでに読み込まれている場合は、そのまま即座に再読み込みされます。

### 新しい言語プリセットのリクエスト

対応してほしい WT Locale がある場合は、[GitHub](https://github.com/jwnetdotwork/nwt-linker) の Issue または Pull Request でお知らせください。

## 設定

設定画面では、次の項目を調整できます。

- 変換機能の有効 / 無効
- 入力停止後の変換待ち時間
- 開く出版物の言語
- 開く出版物
- URL テンプレート

日本語で使用する場合は、既定値のままで問題ありません。

## インストール方法

### 手動インストール

1. GitHub の [Release ページ](https://github.com/jwnetdotwork/nwt-linker/releases) を開き、最新リリースから `main.js` と `manifest.json` をダウンロードします。
2. それらの 2 ファイルを、あなたの vault の次のフォルダに配置します。

```text
<Vault>/.obsidian/plugins/obsidian-nwt-linker/
```

3. Obsidian を再読み込みし、**設定 → コミュニティプラグイン** から NWT Linker を有効にします。

## 補足

- 対応している WT Locale プリセット:
  - 日本語（`J`）
  - 英語（`E`）
  - スペイン語（`S`）
  - 中国語 繁体字（`CH`）
  - 中国語 簡体字（`CHS`）
  - ポルトガル語 ブラジル（`T`）
  - フランス語（`F`）
  - ドイツ語（`X`）
  - 韓国語（`KO`）
  - イタリア語（`I`）
  - ロシア語（`U`）
- 設定した WT Locale に対応するプリセットが存在しない場合、初回セットアップ時に日本語 (`J`) プリセットにフォールバックします。
- このプラグインは Obsidian のコミュニティプラグインです。
- 既定ではオフラインで動作します。
- jw.org の利用規約に準拠しています。スクレイピングは行っていません。
- 聖句リンクの変換は、あなたのノート内で完結します。
- WT Localeの調べ方
  - ご自分の言語でシェアリンクを作成して`wtlocale=大文字アルファベット`の部分を探してください。その大文字アルファベットがWT Localeです。
  - 例) `https://www.jw.org/finder?srcid=jwlshare&wtlocale=E&prefer=lang&bible=40024045&pub=nwtsty` というシェアリンクであれば、WT Localeは`E`です。
